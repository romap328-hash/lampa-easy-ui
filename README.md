# Easy UI — плагин интерфейса для Lampa

Меняет только интерфейс, механики Lampa и онлайн-плагинов не трогает.

- «Смотреть» сразу открывает страницу с сериями, без промежуточного меню.
- Shots скрыт с карточки, из меню и с главной.
- Источник (балансер), озвучка и сезон выбираются в одном меню.
- Прокрутка мягче; фокус пульта «прилипает»: короткий свайп по сенсору — один шаг.

Каждый пункт выключается в «Настройки → Удобный интерфейс».

## Установка

В Lampa: «Настройки → Расширения → Добавить плагин», адрес:

```
https://cdn.jsdelivr.net/gh/romap328-hash/lampa-easy-ui@main/easy_ui.js
```

Проверено на Lampa 3.4.7.
