# Easy UI — плагин интерфейса для Lampa

Меняет интерфейс и порядок действий. Механики Lampa и онлайн-модов не трогает: фильмы ищут и отдают установленные моды (Online Mod, моды на Lampac и другие).

- **Новая карточка фильма.** Название, эмоции и кнопки внизу поверх фона; маленький постер убран, его можно открыть во весь экран кнопкой «Постер». «Смотреть» — большая синяя, остальные кнопки мельче, рядом с ней.
- **Одна кнопка «Смотреть».** Открывает мод, выбранный в прошлый раз. Остальные — по кнопке «Источники». Shots убран с карточки, из меню и с главной.
- **Шапка на странице мода.** Видимые кнопки «Сезон», «Озвучка», «Сервер» с текущим значением вместо «Сортировать» и «Фильтр». «Назад» в списке серий сразу поднимает к шапке, второе «Назад» — выход.
- **Серии плиткой.** По три в ряд вместо длинного списка.
- **Сначала русская озвучка.** Если включились субтитры или оригинал, плагин ставит русскую озвучку, а если её нет — пробует другие серверы. Озвучку, выбранную вручную, не меняет.
- **Автоподбор сервера.** Пустой или зависший сервер (в модах он называется «балансер») — переключение на следующий. Начинает с тех, что уже находили этот фильм или находят чаще. Моды, которые проверяют серверы сами, не трогает.
- **Цепочка модов.** Если мод не нашёл фильм ни на одном сервере, сам открывается следующий мод.
- **Понятные слова.** «Балансер» в интерфейсе модов заменён на «сервер».
- **Озвучка в плеере.** Во время просмотра кнопка звука показывает озвучки мода. Выбор переключает озвучку и снова включает ту же серию; место просмотра восстанавливает мод.
- **Пульт.** Короткий свайп по сенсору — один шаг; фокус не проскакивает кнопки и не уходит в другой ряд.

Каждый пункт выключается в «Настройки → Удобный интерфейс». Там же видна версия.

## Установка

В Lampa: «Настройки → Расширения → Добавить плагин», адрес:

```
https://cdn.jsdelivr.net/gh/romap328-hash/lampa-easy-ui@main/loader.js
```

Это загрузчик: он всегда подтягивает свежую версию плагина. Ставится один раз.

Если раньше был добавлен адрес с `easy_ui.js` — удалите его, иначе может загрузиться старая версия.

После запуска Lampa внизу появится «Удобный интерфейс 0.6.0 включён» (один раз на каждую новую версию).

Проверено на Lampa 3.4.7.
